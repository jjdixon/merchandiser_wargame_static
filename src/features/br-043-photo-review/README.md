# br-043-photo-review

**Requirements:** BR-043 Reporting, dashboards and centralized photo review · on by default.

## What it does
**Photo review tab:**
- **Queue:** every display result that came with a photo and hasn't been reviewed,
  suspected non-compliance first: recognition says non-compliant or partial,
  recognition disagrees with a "compliant" report, low confidence, reported
  partial/non-compliant. Confirm, or change the result; it becomes the display's
  result (core review event).
- **Dashboard:** planned, due today, done today, overdue, absent, non/partial and
  compliant, with the compliance rate against the goal (setting, default 80%), by
  merchandiser, store, banner, market, route type or day. Worst first.

## War-game check
- Can a manager clear a day's photos in minutes? What makes them trust a photo?
- Is a single compliance rate enough, or do they need it by brand / display type?
