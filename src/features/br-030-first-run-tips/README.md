# br-030-first-run-tips

**Requirements:** BR-030 Training and in-app guidance · on by default.

## What it does
A short tip at the top of each tab the first time it's opened (`tips.json`, by tab
id), dismissed with *Got it* and remembered in the browser. *Show tips again* is on
the Pay & labor rules screen.

## War-game check
Give a new player only the tips and see whether they can run a day unaided; log
where they get stuck as findings.
